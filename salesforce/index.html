The Salesforce AI Platform

Agentforce doesn't stand alone — it's powered by a layered architecture. Understanding each layer is the key to building reliable, scalable AI solutions.

🤖
Agentforce

Autonomous agent runtime — handles user sessions, reasoning loops, and action dispatch.

🧠
Atlas Reasoning Engine

LLM-based planning layer that decides which topics and actions to invoke each turn.

☁️
Data Cloud

Real-time CDP powering unified profiles, vector search, and RAG grounding for agents.

🛡️
Einstein Trust Layer

Security middleware: PII masking, toxicity filtering, zero data retention, audit logging.

⚡
Flow Builder & Apex

Action execution layer — the business logic agents invoke to read and write data.
