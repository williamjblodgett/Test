Tableau API

Automate, integrate, and extend Tableau's powerful data visualization platform using REST, Hyper, and Extensions APIs.

🔍 What Is the Tableau API?

Tableau provides a suite of APIs that let developers and analysts automate administrative tasks, embed dashboards in external apps, push data programmatically, and build custom extensions. Rather than clicking through the Tableau UI manually, you can write code that manages hundreds of workbooks, users, or data sources at once.

With Tableau AI (formerly Tableau Pulse and Einstein), you can also surface AI-generated insights and natural-language data explanations directly in dashboards.

💡 Tableau is now part of Salesforce and integrates with Data Cloud, making it a key component of the Salesforce AI stack.

👤 Who Is It For?

Data Analysts

Automate publishing, refresh schedules, and user permissions.

Developers

Embed Tableau views in web apps and build custom dashboard extensions.

Data Engineers

Push large datasets to Tableau using the Hyper API for fast in-memory analytics.

IT/Admins

Manage site settings, groups, schedules, and content at scale via REST API.

📚 Key Concepts

Tableau REST API

  • HTTP-based API for managing Tableau Server / Tableau Cloud programmatically
  • Authenticate with Personal Access Tokens (PAT) or username/password
  • Key endpoints: /workbooks, /datasources, /users, /views, /jobs
  • Supports pagination, filtering, and field selection for efficient queries

Tableau Hyper API

  • Python/C++ library to create and read .hyper extract files
  • Optimized for high-performance in-memory data operations
  • Use cases: large ETL jobs, custom data extracts, bulk data pushes
  • Supports insert, update, delete operations on extract files

Tableau Extensions API (JavaScript)

  • Build custom web apps that run inside Tableau dashboard zones
  • Access dashboard data, filter views, and react to user interactions
  • Requires basic HTML/CSS/JavaScript knowledge
  • Extensions are hosted on any web server and loaded by URL

Embedding API (Tableau Embedding API v3)

  • Embed Tableau views into your own web applications with a Web Component
  • Control filters, parameters, and marks programmatically via JavaScript
  • Supports SSO via Connected Apps or JWT authentication

Tableau AI (Tableau Pulse / Einstein)

  • AI-generated metric insights surfaced directly in dashboards
  • Natural language answers to data questions
  • Automated anomaly detection and trend explanations

🚀 Quick-Start Tips

  1. Get a Free Account: Sign up for Tableau Public (free) to start building visualizations without a server.
  2. Learn REST API basics: Use Postman or curl to authenticate and list your workbooks via GET /api/2.8/auth/signin.
  3. Try the Hyper API samples: Clone the official GitHub repo and run the Python sample scripts to create your first .hyper file.
  4. Build an Extension: Use the Tableau Extensions API scaffold on GitHub to build a simple HTML dashboard extension in under 1 hour.
  5. Enable Tableau AI: Explore Tableau Pulse in Tableau Cloud to see AI-generated metric summaries in action.
